Writes one original sentence explaining the modern internet to a time traveler from 1800, using only words and pictures a person from that year could already hold in their head: every library and post office on earth folded into a single room, where a letter posted at breakfast is read across the sea before your tea cools. Deterministic, model-free Python with no dependencies. The sentence is validated on every run (exactly one sentence, non-empty, at most 200 characters) and the program refuses to write an invalid line.

## Run it

```sh
python3 main.py
```

Check the sentence without writing anything:

```sh
python3 main.py --verify
```
